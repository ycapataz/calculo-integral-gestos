4. Consejos sobre los límites

  • Escribe solo números: 0, 2, 3.5, -1.
  • No escribas pi en los límites.
  • Si a > b, el resultado cambia de signo.
  • Evita a = b: la integral dará 0.

Reglas rápidas

  • Multiplica con *: 2*x, no 2x.
  • Usa abs(x) en lugar de |x|.
  • Usa sqrt(x) en lugar de √x.
  • Usa log(x) en lugar de ln(x).

Ejemplos paso a paso

A · Área de una parábola

f(x) = x**2 · a = 0 · b = 2 · 1 dedo

A = 8/3 ≈ 2.6667 u²

B · Volumen de un cono

f(x) = x · a = 0 · b = 3 · 2 dedos

V = 9π ≈ 28.2743 u³

C · Longitud de arco

f(x) = x · a = 0 · b = 1 · 5 dedos

L = √2 ≈ 1.4142 u

D · Superficie de una esfera

f(x) = sqrt(1 - x**2) · a = -1 · b = 1 · 4 dedos

S = 2π ≈ 6.2832 u²

Gestos con la mano

DedosOperaciónFórmula
1Área bajo la curvaA = ∫[a,b] |f(x)| dx
2Volumen eje XV = π ∫[a,b] [f(x)]² dx
3Volumen eje YV = 2π ∫[a,b] |x|·|f(x)| dx
4SuperficieS = 2π ∫[a,b] |f(x)|·√(1+[f'(x)]²) dx
5Longitud de arcoL = ∫[a,b] √(1+[f'(x)]²) dx

Funciones especiales

  • Si SymPy falla, se usa integración numérica con SciPy.
  • Resultados infinitos o NaN → «No evaluable (Indeterminado)».
  • Integrales divergentes (ej: 1/x con a=0) → indeterminadas.
